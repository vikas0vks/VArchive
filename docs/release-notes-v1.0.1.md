# VArchive v1.0.1 Stable

VArchive v1.0.1 Stable introduces a complete visual identity refresh while preserving the tested archive engine and security boundaries from v1.0.0. The signed APK is ready for direct installation and everyday use.

## What's new

- New original VArchive brand mark combining a geometric V, zipper, and secure archive container.
- New full-color Android adaptive launcher icon.
- New monochrome themed icon for supported Android launchers.
- Branded Android splash screen, Home screen, and About dialog.
- Updated GitHub README hero and real-device screenshots.

## Archive capabilities

- Create ZIP/ZIP64, 7Z, TAR, TGZ, TBZ2, TXZ, TAR.ZST, GZIP, BZIP2, XZ, and ZSTD archives.
- Browse, test, and extract those formats plus RAR/RAR5, AR/DEB outer containers, and CPIO.
- Create and extract AES-256 encrypted ZIP archives.
- Use Android's Storage Access Framework without broad storage permission.
